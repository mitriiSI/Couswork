# Библиотека

Статический сайт для хранения книг и ссылок. Откройте `index.html` (или выложите папку на GitHub Pages / любой хостинг).
Данные хранятся в браузере (IndexedDB); экспорт/импорт JSON — кнопка слева вверху.

## Запись экрана для Windows

В папке [`screen-recorder`](screen-recorder/) лежит программа для записи экрана, звука компьютера, микрофона и веб-камеры. Готовый `ScreenRecorder.exe` можно скачать во вкладке Releases.
